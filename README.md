# Hospital Management System (SQL Project)

SQL based Hospital Management System designed to manage patients, doctors, appointments, treatments, and billing with business insights and analysis.

## Project Description
This project focuses on designing a relational database for a hospital management system using SQL. It helps in managing patient records, doctor information, appointments, treatments, and billing details efficiently.

## Objectives
- Design a structured hospital database  
- Manage patient and doctor records  
- Track appointments and treatments  
- Handle billing and payment details  
- Perform SQL-based data analysis  

## Technologies Used
- SQL  
- MySQL  

## Database Tables
- Patients  
- Doctors  
- Appointments  
- Treatments  
- Billing  

## Key Features
- Use of primary and foreign keys  
- Real-world hospital database structure  
- Appointment and treatment tracking  
- Billing, insurance, and discount management  
- Analytical queries for insights  

## Insights & Analysis
A separate SQL file is included to generate insights such as:
- Total number of patients  
- Gender and city-wise patient distribution  
- Doctor specialization and experience analysis  
- Appointment status and visit type analysis  
- Revenue, pending payments, and discounts  
- Doctor-wise and department-wise earnings  

## How to Run
1. Install MySQL  
2. Open MySQL Workbench  
3. Execute the hospital_management.sql file  
4. Run hospital_insights.sql for analysis  

## Project Files
- hospital_management.sql  
- hospital_insights.sql

## Conclusion
This project provides practical exposure to SQL database design and data analysis in the healthcare domain and is suitable for students and beginners.
